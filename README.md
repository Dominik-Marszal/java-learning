# Java Exercises

Exercises written while learning Java, grouped by stage.

## Contents

- `Stage1.java` — basics: variables and types, Scanner input, calculator, switch, arrays, sum and average
- `Stage2.java` — collections: List, Map, Set
- `Stage3.java` — OOP: encapsulation, inheritance, interfaces, polymorphism
- `Stage4.java` — exception handling: try/catch/finally, throw
- `Stage5.java` — lambdas, streams, generics, file I/O, threads, to-do list saved to a file
- `IsPrimetxt.java` — reads numbers from `numbers.txt`, keeps the primes with a stream, writes them to `primes.txt`

## Running

Open the project in IntelliJ IDEA and run the `main` method of the chosen class. Each class contains numbered exercise methods called from `main`.
